## 免責條款設計（v3）

網站已加入三層提醒：
1. 研究區上方的「重要提醒」
2. AI 分析區的資料限制提示
3. 頁尾完整免責聲明 + 可開啟的完整條款視窗

核心原則：網站只做公開資訊整理與研究參考，不提供買賣推薦或保證獲利；AI 摘要不保證完整、正確或即時；正式接入資料前須確認來源授權與再散布條件。

## v4：第一階段真功能
- 股票名稱／代號識別器已加入，支援 2330、2317、2454、0050 等常用入口。
- 搜尋後會動態更新研究頁，不再只是固定顯示 2330。
- 新增「來源中心」，先把 MOPS 與政府資料開放平臺列為候選官方／公開來源。
- 暫時不顯示虛構股價、PE、EPS 等數字，避免 DEMO 數字被誤認為真實行情。
- 即時／延遲行情仍維持關閉，待確認 TWSE 授權後再接。
- 免責條款與風險提醒固定保留。


## v5 更新
- 新增「官方公司資料」入口。
- 依股票代號動態建立 TWSE 公司基本資料、TWSE 財務分析、MOPS 重大訊息原始連結。
- 第一階段仍不在前端自行顯示即時／延遲行情；優先引導使用者查看原始官方資料。
- 免責條款固定保留。


## v7 更新
- 新增 AI Research Assistant 示範對話區。
- 快速提問會直接帶入 AI 助手。
- AI 回答元件固定顯示資料來源規則與免責聲明。
- 目前仍為 Demo，不含真實 AI API 與即時行情；正式 API 應由 Cloudflare Worker 等後端代理。

## v8 後端

新增 `worker/`：Cloudflare Worker 後端骨架。AI API Key 不放 GitHub 前端；部署時使用 Cloudflare Worker Secrets。正式資料 adapter 接入前，Worker 仍不提供 TWSE 即時／延遲行情。

## v9：第一個真正資料 Adapter

StockAI v9 已加入 Cloudflare Worker 的 `/api/stock-profile`，以 TWSE OpenAPI／政府開放資料的上市公司基本資料作為第一個受政策檢查的公開資料來源。政府資料開放平臺資料集 18419 標示免費、政府資料開放授權條款第1版。

前端仍預設 `ENABLE_LIVE_BACKEND: false`，部署 Worker 並測試成功後才開啟。


## v10：官方月營收 Adapter
- `GET /api/monthly-revenue?symbol=2330`
- 使用 TWSE OpenAPI `t187ap05_L`，對應政府資料開放平臺資料集 94026。
- 顯示最新一期月營收、月增率、年增率與累計營收。
- 金額統一顯示為新臺幣百萬元，原始資料單位為新臺幣千元。
- 目前端點是最新一期快照，不假裝提供歷史月份。
- 來源與資料日期會跟著結果回傳。
- ETF 不套用公司月營收。
